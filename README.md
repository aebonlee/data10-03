# data10-03 · 검사 기준서 작성 자동화

PDF 도면(벡터)의 치수 · 공차 · 기하공차 · 용접 표기를 인식해 번호 풍선을 자동으로 달고(목표 1), 풍선이 이미 있는 도면에서는 풍선별 정보를 엑셀로 뽑고(목표 2), 무엇보다 먼저 정답과 대조해 인식 일치율을 재는 브라우저 도구

| 항목 | 내용 |
|---|---|
| 제출자 | 황수용 |
| 과정 | 현장 데이터 디지털화 전문가과정 2차수 (2026) |
| 진행 단계 | 1단계 개발 완료 (2026-10-20) — https://aebonlee.github.io/data10-03/ |
| 다음 개발 | 2단계 — 실제 도면 2~3장 · 정답으로 일치율 측정과 규칙 보정, 스캔 도면 OCR, 원본 벡터를 유지한 풍선 PDF, 회사 검사 기준서 양식 출력 |

> 실제 도면은 아직 받지 않았습니다. 들어 있는 예시는 **직접 만든 가상 도면 3종**(브래킷 · 용접 구조물 · 축)입니다. 회사 도면은 이 리포에 넣지 않습니다.

## 실행 방법

**온라인에서 바로 보기: https://aebonlee.github.io/data10-03/**

처음 열면 대시보드입니다. 예시 도면 카드에서 **「풍선 없음 → 목표 1」** 이나 **「풍선 있음 → 목표 2」** 를 누르면 가상 도면이 열립니다. 「일치율 측정」 에서 **「예시 정답 불러오기」** 를 누르면 정답과 대조한 숫자가 나옵니다.
실제로 쓸 때는 「도면 열기·인식」 에서 PDF 를 고르면 됩니다. 파일은 서버로 보내지 않고 이 브라우저 안에서만 읽고 저장합니다.

내 PC 에서 열려면 `index.html` 을 더블클릭하거나, 폴더에서 `python3 -m http.server 8000` 후 `http://localhost:8000` 을 엽니다. 외부 CDN 을 부르지 않습니다(PDF 는 `vendor/pdfjs` 의 pdf.js, 엑셀은 `vendor/` 의 SheetJS).

## 예시 도면 일치율 (2026-10-20 측정)

`node scripts/measure-samples.mjs` 결과입니다. **값 일치율 = 정답 항목 중 구분 · 공칭값 · 상한 · 하한까지 모두 맞은 비율** 이고, 「85%」 는 이 숫자로 봅니다.

| 도면 | 정답 | 목표 1 (풍선 없음 → 자동 배치) | 목표 2 (풍선 있음 → 풍선 읽기) |
|---|---|---|---|
| A 브래킷 (치수 · 쌓인 공차 · H7 · 기하공차 · 나사 · 각도 · Ra) | 14 | 100% (번호 같음 7.1%) | 100% |
| B 용접 구조물 (필릿 · a4 · 단속 · 형상만 있는 용접 · 평행도) | 13 | 100% (번호 같음 7.7%) | 100% |
| C 축 (g6 · k6 · 동심도 · 흔들림 · 나사 등급 · 선으로 그린 「8」) | 12 | 91.7% — 「8」 놓침 | 91.7% — 「8」 풍선은 연결 못 함 |
| 합계 | 78 | | 76 / 78 = 97.4% · 정밀도 100% |

- **이 숫자를 실제 도면의 수준으로 읽으면 안 됩니다.** 예시 도면은 규칙을 만든 쪽이 만든 것이라 높게 나오는 것이 당연합니다. 실제 도면 2~3장과 정답(기획서 10장 ①)을 받으면 같은 화면 · 같은 스크립트로 다시 잽니다.
- 도면 C 의 「8」 은 글자가 아니라 선으로 그려 넣었습니다. 1단계(글자 층 규칙)로는 못 읽는 것이 정상이고, 그 한계가 일치율에 그대로 드러나는지 보려고 넣었습니다(2단계 OCR 대상).
- 「번호 같음」 이 낮은 것은 정답의 번호를 사람이 보기별로 묶어 매겼기 때문입니다. 값으로는 모두 짝이 맞습니다. 회사의 번호 매기는 규칙(기획서 10장 ⑤)을 받으면 순서 방식을 맞춥니다.

## 한계 (솔직하게)

- **벡터 PDF 만 읽습니다.** CAD 에서 내보내 글자를 마우스로 고를 수 있는 PDF 여야 합니다. 스캔 그림 · 글자를 선으로 바꾼 PDF(CAD 의 「글자를 윤곽선으로」 설정)는 읽지 못합니다.
- **규칙(휴리스틱)입니다.** 치수 형식 정규식, 표제란 낱말, 원 · 지시선 · 직각 삼각형의 기하로 판단합니다. 회사 도면 양식(표제란 칸 이름 · 풍선 모양 · 용접 표기 관행 · 특수 글꼴로 쓴 기하공차 기호)이 다르면 맞춰야 합니다 — 그래서 측정부터 합니다.
- 기하공차 기호는 유니코드 글자(⏥ ⊥ ∥ ◎ ↗ 등)로 들어 있을 때만 알아봅니다. CAD 가 전용 기호 글꼴의 다른 글자(예: 「j」)로 내보내면 대응표를 더해야 합니다.
- 끼워맞춤 공차는 ISO 286 의 자주 쓰는 등급(H · G · F · h · g · f · js · k · m · n · p, IT5~9, 지름 180mm 이하)만 환산합니다. 그 밖은 「확인 필요」 로 남깁니다.
- 풍선 인식은 「원(곡선) 안의 1~3자리 정수」 입니다. 다각형 · 깃발 모양 풍선, 원 없이 숫자만 있는 풍선은 설정의 「홀로 있는 숫자도 풍선으로」 를 켜야 하고 잘못 잡을 수 있습니다.
